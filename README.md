# MRCT

中美多区域临床试验公开登记资料集。数据快照：2026-10-20；按 NCT 编号去重，所有案例待人工复核。

## 下载完整资料

约 3.61 GB 的完整 ZIP 以两个分卷作为 Release 附件提供：[完整资料下载页](https://github.com/Sunnyglow-jump/MRCT/releases/latest)。普通仓库仅存说明、汇总工作簿和校验清单。

下载同一 Release 的全部文件到同一个文件夹：

1. `MRCT-data.zip.001`
2. `MRCT-data.zip.002`
3. `manifest.json`
4. `join_parts.py`
5. `SHA256SUMS.txt`

在有 Python 3 的环境运行：

```text
python join_parts.py
```

程序逐卷验证 SHA-256，合并为 `MRCT-data.zip` 并核对完整文件校验值；之后用 ZIP 解压工具解压。分卷不能单独作为普通 ZIP 解压。完整解压后，从工作簿所在目录解析 `relative_path`，保持目录结构。

## 来源与范围

来源为 [ClinicalTrials.gov](https://clinicaltrials.gov/) 官方登记及其公开附件。检索条件：

```text
AREA[Phase]PHASE3 AND AREA[StudyType]INTERVENTIONAL AND AREA[HasResults]true
```

同一NCT的当前研究地点、历史已移除国家，或同一基线地区指标中的非零人数用于寻找中国大陆与美国的参与证据。港澳台单独标记，不替代大陆条件。

此前14,808条历史检索仅完整保存前1,000条；本批按相同条件重新获取14,822条，不宣称与旧集合逐条一致。

## 文件内容

完整包含原10张工作表格式的Excel、`cases/`原始资料与`batch_metadata/`筛选日志和校验记录。登记事实保留原始字段路径、文件链接和证据分层；缺失和未核查字段不填为零。

登记地点不等于实际入组，族裔不等于国家；基线各研究臂和总体不得重复相加。共享SAP文件不意味着不同NCT是重复试验。

所有记录均为 `awaiting_review`，未代填人工验收。未完成论文和FDA/EMA/PMDA审评资料的逐例系统核查。含结果的登记资料标记为`reference_only`，方案/SAP公开时点未核实的资料暂标记`quarantine`。未获取患者级原始数据。

本仓库是公开来源资料的采集与整理，不代表监管结论。使用时请保留原始来源与证据状态。
